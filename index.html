01 / ARCHITECTURE

A separation of powers.

Program evolution rests on three decisions — govern, propose, judge. Existing systems let one owner absorb another, and none keeps the judge private. EvoTrias gives each decision its own plane. Planes exchange typed contracts only — and a hook layer makes sure no plane can erode another.

01Skill + MCP control plane

Structured Governance

owns govern · what spans rounds

Distills settled outcomes into posterior evidence, adapts the selection policy, persists validated experience, and binds each new task's context capsule.

  • Posterior evidence at artifact · lineage · global scope
  • Adaptive lineage / parent / inspiration policy
  • Notes & Meta-guidance, validated before commit
02your coding agent

Open Proposal

owns propose · what happens inside a task

A general-purpose coding agent — Claude Code, OpenCode, Codex — pulls its capsule over MCP, then reasons and calls tools on its own until an artifact exists.

  • Parallel task executors in a rolling queue
  • No mutation template: implement, build, test, repair
  • Distills typed notes and proposes new directions
03isolated evaluator

Protected Judgment

owns judge · what counts

Contract-visible, evidence-private. The artifact enters through a narrow interface; only a normalized outcome — validity, fitness, metrics — comes back.

  • Instruction: every prompt states the prohibition
  • Isolation: evaluator behind a request interface
  • Enforcement: hooks deny evaluator reads
THE CONTRACT LOOP

Three planes. Three typed contracts.

Γt=G(ℋt)Governance binds a context capsule
xt=P(R𝒬, C𝒬, Γt)Proposal submits a candidate artifact
yt=J𝒬(xt)Judgment returns a normalized outcome

Each settled outcome merges into the history ℋ and shapes only later bindings. The contracts fix the semantics of G and J independently of how P is implemented — so any host that meets them can supply candidate construction.

Scheduler hooksSole writer of the task pool. Scheduling follows what happened, not what an agent reports.

Permission hooksBefore every tool call: no evaluator reads, no peeking at other tasks' results.
